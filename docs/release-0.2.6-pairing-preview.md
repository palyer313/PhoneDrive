# PhoneDrive 0.2.6 Pairing Preview

这是发布前候选的历史记录；当前正式版及更新后的验证范围见 [0.2.6 正式版说明](release-0.2.6.md)。

Windows / Android 本地候选修正，针对多网卡配对、Android 扫码强制横屏，以及启动服务前缺少 Wi-Fi 提示的问题。本次 Android 有代码改动，需要安装新的 APK；当时该候选尚未公开发布。

## 连接条件

配对二维码里的地址必须能被扫码手机主动访问。电脑通过手机 USB 网络共享上网，只能证明电脑可以访问外部网络；其他 Wi-Fi 设备不一定能反向访问 USB 共享网段里的电脑。

推荐让电脑同时连接手机所在的 Wi-Fi，然后重新打开配对窗口或点击“刷新二维码”。USB 网络共享可以保留。若必须保持电脑只用 USB 共享，可在手机显示配对信息，再由电脑在设备列表中选择该手机并输入手机显示的六位配对码；指纹仍须按界面核对，不跳过身份校验。

## 修改

- 二维码网卡选择优先普通局域网接口，再结合已知设备子网、网关和接口类型排序，USB RNDIS 共享及虚拟网卡仍可手动选择。
- 地址列表显示网卡名称，并标明 USB 共享或虚拟网络；仅有共享网络时说明反向连接的限制及替代连接方法。
- “刷新二维码”重新检测当前网卡，连接 Wi-Fi 后可以更新地址；切换地址或创建失败时清除旧二维码。
- 保留临时邀请、TLS 身份绑定、完整 Host Key 验证与电脑端配对确认。没有更改防火墙、系统网络配置、配对记录或密钥。
- Android 扫码页取消强制横屏和方向锁，遵循系统旋转设置；手机可竖屏，平板也可按系统设置使用横屏。
- 手动点击“启动服务”前检查 Wi-Fi：关闭和已开启但未连接分别提示；提供 Wi-Fi 设置、重试和取消。设置返回后重新检测，连接就绪则继续原启动请求。
- 有效热点、USB 或有线局域网仍可启动。不要求局域网具备互联网连接，不申请定位或 SSID 权限，不自动打开 Wi-Fi，不增加后台轮询或开机服务重启。

## 验证与边界

- Windows Release 构建通过，Core 48 项测试通过，包括 USB 优先级回归、只剩 USB 时可选、非 /24 子网及原有配对安全测试。
- Android Release 构建和单元测试验证包括 Wi-Fi 关闭、开关已开但未取得局域网地址、仅本地 Wi-Fi，以及热点/USB/有线网络可用的启动规则。实际扫码旋转和 Wi-Fi 设置返回的真机界面仍待验收。
- 本机网络只读检查确认当前为 USB RNDIS 共享，电脑 Wi-Fi 断开。电脑主动连接已知手机 SFTP 端口成功；不能据此证明手机反向连接电脑也成功。
- 实时 Windows 窗口验证工具初始化失败，实际窗口显示和点击操作尚未验证。真实扫码配对仍需选择可互通网络后验收；当前修改不能为原本不通的网段自动建立路由。
- 0.2.5 的上传流水线和省电修改保留，本轮没有重做传输速度验收。Windows 安装包已构建，覆盖安装尚未验证。

## 使用和回退

先从托盘退出旧版 Windows 程序，再安装或运行 `Windows/PhoneDrive.exe`。Android 包为 `Android/PhoneDrive-0.2.6-pairing-preview.apk`，versionCode 7，保持原签名，可覆盖旧版。原配对数据与设置保留。需要回退 Windows 时退出此候选并运行原 0.2.5；Android 直接降级通常会被系统拒绝，请勿通过清除应用数据强行回退。
