# PhoneDrive 0.2.5 Performance Preview

本版改进应用内电脑→Android 首次上传性能，并调整 Android 共享服务的空闲唤醒与恢复行为。仍为预发布版。

## 下载与升级

- Windows 安装版：`PhoneDrive-0.2.5-performance-preview-Setup-x64.exe`，包含 .NET 运行时。
- Windows 免安装版：`PhoneDrive-Windows-0.2.5-performance-preview-x64.zip`，解压后运行 `Windows/PhoneDrive.exe`。
- Android：`PhoneDrive-0.2.5-power-preview.apk`。Android 内部版本名保留为 `0.2.5-power-preview`（versionCode 6），属于同批更新，签名与 0.2.4 一致，可覆盖升级。
- 对应源码：`PhoneDrive-0.2.5-performance-preview-source.zip`；摘要：`SHA256SUMS.txt`；审查范围：`publication-review.json`。

先从系统托盘退出旧版 Windows 程序，再安装或运行新版。配对与设置保存在应用目录之外，保留原配对数据；请勿为升级清除手机应用数据。挂载驱动仍需独立安装官方 WinFsp 与 SSHFS-Win。

## 改动

- 应用内本地→SFTP 首次上传改用异步流水线，最多 64 个未确认 WRITE；写入确认后才释放窗口名额，等待确认有超时限制。
- 每个上传使用独立会话并重新核验固定 Host Key。取消或失败释放该会话，不关闭设备浏览会话。
- 保留临时文件、大小与 SHA-256 检查、源文件复核、提交后校验以及移动前源文件保护。已有部分文件的续传仍走原偏移写入路径。
- Android CPU 唤醒锁只在真实文件读写时触发，约 15 秒空闲后释放，并设置安全超时；修复容量 SFTP 工厂没有转发监听器的问题。
- “服务被系统结束后自动恢复”独立于开机启动，默认关闭；合并批量任务的服务启动请求，停止服务不再通过启动服务发送停止命令。
- Windows 关于窗口及启动日志读取实际构建版本。

## 实测与验证

Note11、同一局域网 5 GHz Wi-Fi、PhoneDrive 前台亮屏、同一预生成 1 GiB 随机文件，连续三轮使用实际 TransferEngine。BufferSize 为 32 KiB，有界窗口 64；保持 SSH 加密与固定 Host Key，不更改厂商自启动或电池无限制设置。

| 轮次 | 上传平均 MiB/s | 最低完整一秒上传 MiB/s | 包含全部校验的全流程 MiB/s | 全流程秒数 |
|---|---:|---:|---:|---:|
| 1 | 36.21 | 31.86 | 11.79 | 86.85 |
| 2 | 36.11 | 31.42 | 11.94 | 85.77 |
| 3 | 36.39 | 32.09 | 12.08 | 84.74 |

三轮 SHA-256 均与预生成负载一致。全流程包含源文件检查、上传、两次完整远端读回校验及提交，不包含测试后的清理。81 个完整约一秒上传样本均高于 10 MiB/s，没有零进度的完整样本；首尾不足一秒区间不纳入最低值统计，不能据此排除低于一秒的短暂波动。

本轮用户指定的测试停止门限为 45℃，最高采样电池温度 40.6℃；这是测试条件，不是修改系统温控。约每两秒采样的前台、亮屏、共享服务状态均满足条件。所有测试文件与临时盘符已清理。

验证层次：

- Windows Release 与 Android Release 构建通过；Core 44 项、Android 7 项单元测试通过。
- 实际 MINA SFTP 集成通过：流水线复制、暂停/恢复、取消清理、取消不影响浏览、取消后重试、有效前缀续传、错误 Host Key 拒绝与原文件保护。对最终打包的 Core DLL 重新执行集成验证通过。
- Android 真机小文件 I/O 与 SHA-256 通过：传输前无持续 CPU 锁，传输中取得锁，结束空闲 18 秒后无锁。尚未量化实际电量改善。
- Windows 安装包已构建，本轮尚未在日用安装目录做覆盖安装与卸载验收。

## 仍需验证

- **资源管理器挂载盘符复制是独立路径。** 默认挂载的 FileStream 64 MiB 短测约 9.71 MiB/s；AES-GCM 配合 Win32 CopyFileEx 的短测约 12.93 MiB/s，尚未完成同条件三轮大文件验收。本版未更改生产挂载的加密算法或写块参数。
- 已有部分文件的续传路径尚未加速；大量小文件、多任务并发、其他设备和网络不能保证与上述结果一致。
- Android 长时间后台、熄屏及各厂商系统恢复行为仍需日常使用验证；手机管家的历史频繁自启提示是否消失、实际耗电改善多少尚无充分证据。
- 服务端 SHA-256 扩展尚未进入产品，本版没有通过省略校验提速。

## 发布审查与回退

发布内容不包含签名私钥、设备配对记录、本机设置、测试负载、原始设备日志或调试符号。编译时强制重建引用项目，映射源码路径并移除调试符号，避免旧程序集携带本机 PDB 路径。具体检查范围与限制见发布附件 `publication-review.json`；这不是对任意个人信息或所有安全问题的全面审计。

回退 Windows 时先退出候选程序，再运行保留的 0.2.4，并保留现有用户数据。Android 因 versionCode 增加，系统通常不允许直接覆盖降级；请勿通过卸载清除数据来强行回退，有需要时应提供保留签名及数据兼容性的回退构建。
