# PhoneDrive 0.2.7 发布说明

## 本次功能

- Android 设置 → 共享范围与权限：浏览文件夹、返回上一级、选择当前文件夹、在当前目录新建文件夹。保存后重启手机文件服务生效，不自动中断传输。保护内部共享存储边界及 Android/data、Android/obb 限制。
- Windows 重复启动会唤起原来的主窗口；隐藏到托盘和最小化状态均恢复，新进程退出。修复旧版 StartupUri=null 导致的异常。
- 两端设置提供跟随系统、浅色、夜间模式，以及海蓝、翡翠、紫罗兰、玫瑰、琥珀预设主题色；支持颜色盘和 #RRGGBB 输入。主题设置持久保存。Windows 的系统原生选色、文件夹及消息框仍遵循 Windows 自身外观。
- Android 文件管理器和相册的系统分享列表可选择 PhoneDrive，支持单文件或最多 100 个文件/图片，随后选择已配对的 Windows 电脑。
- Windows 首次接收手机分享时提示保存位置，默认读取系统真正的下载文件夹（支持已迁移的位置）。可在设置中选择其他目录或恢复系统下载目录。同名文件追加编号，不覆盖已有内容。

## 使用与升级

1. Windows 从托盘退出旧版，运行安装包覆盖升级；免安装版解压后运行 Windows/PhoneDrive.exe。不要删除 AppData/Local/PhoneDrive 配对与设置数据。
2. Android 安装 PhoneDrive-0.2.7-release.apk 覆盖升级；versionCode 9，沿用旧版发布签名。不要先卸载或清除数据。
3. 分享要求双方升级到本版本、处于可互访网络，电脑运行 PhoneDrive 并已连接手机。关闭自动连接时请先在电脑上手动连接手机。手机发起分享会启动其文件服务。
4. 从相册或文件管理器选择文件 → 分享 → PhoneDrive → 选择电脑 → 发送。电脑第一次接收时选择默认下载目录或其他文件夹；接收进度与重试在电脑传输队列中查看。
5. 手机使用当前共享目录内的 .phonedrive-share 暂存选定内容，原文件保持不变。手机分享页面收到完成回执后清理本次暂存。如果提前关闭页面、授权只读导致回执无法写入，或连接中断，暂存会保留，电脑传输队列是接收结果的依据；确认接收后可手动清理对应暂存。只读权限不会被自动更改。

## 验证范围

- Windows Release 自带运行时发布构建、Android 签名 Release 构建通过。
- Windows Core 48 项测试、Android 15 项测试通过。Android 新增文件夹创建、名称校验、目录边界及同名保护测试。
- 独立数据目录完成 10 项分享接收检查：包括实际认证及固定 Host Key 的 SFTP 回环传输、中文/空文件、重名保护、清单哈希拒绝、完成回执和持久日志去重。
- Windows 真实桌面测试：重复启动恢复同一实例且新进程退出、设置布局、系统颜色盘打开、预设颜色保存并应用主界面、夜间模式重启恢复。
- 传输引擎代码与 0.2.6 相同，继续使用其校验与安全提交流程；本轮未重复大文件性能长测。
- 尚未覆盖日用 Windows 安装，也未在真实手机覆盖安装后完成相册分享/文件夹浏览/主题手势验收。构建和回环测试不等于上述真机验收。
- 首次接收选择框的逻辑已实现，接收设置持久化已集成验证；首次弹窗的完整人工选择流程未单独验收。

## 回滚

升级保留配对与设置数据。Windows 升级后若需回退，退出新版并重新运行原 0.2.6 安装包；保留 AppData。Android 系统可能拒绝低 versionCode 覆盖，不要用卸载清数据的方式强制降级，需另行制作同签名高版本号回退包。
