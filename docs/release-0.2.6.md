# PhoneDrive 0.2.6

Windows 桌面端与 Android 端正式发布，集中修正配对地址选择、Android 扫码方向及手动启动共享服务前的网络提示。

| 平台 / 内容 | 文件 |
|---|---|

| Windows x64 免安装版 | `PhoneDrive-Windows-0.2.6-x64.zip` |

Windows：先从托盘退出旧版，再安装或解压运行 `Windows/PhoneDrive.exe`。Android：版本名统一为 `0.2.6`，versionCode 8，保持原签名，可覆盖 0.2.4、0.2.5 和 versionCode 7 的 0.2.6 候选包。升级保留应用数据与配对记录，请勿先卸载或清除数据。

挂载盘符仍需独立安装官方 WinFsp 与 SSHFS-Win，驱动不随本包分发。

## Windows 改动

- 二维码配对地址优先普通局域网接口，再结合已知设备子网、网关和接口类型排序；USB RNDIS 共享与虚拟网卡仍可手动选择。
- 地址列表显示网卡名称、USB 共享或虚拟网络标识，提示手机能否反向访问该地址。
- “刷新二维码”重新检测网卡；切换地址或创建失败时清除旧二维码。
- 保留邀请有效期、TLS 身份绑定、固定 Host Key 核验与电脑端配对确认。

电脑通过另一部手机 USB 共享上网，不代表 Wi-Fi 上的其他手机能反向连接到电脑。配对双方仍需可互访；网卡选择修正不会自动建立跨网段路由。建议电脑与扫码手机连接到同一可互访局域网，随后刷新二维码。

## Android 改动

- 扫码页取消强制横屏与方向锁，遵循系统旋转设置。手机可竖屏扫码，平板按系统设置使用相应方向。
- 点击“启动服务”前区分 Wi-Fi 关闭、Wi-Fi 已开但未取得局域网地址的情况，提供“Wi-Fi 设置”“重试启动”“取消”。
- 从 Wi-Fi 设置返回后重新检查，连接就绪时继续启动请求；启动中按钮禁用，减少重复点击。
- 已就绪的热点、USB 或有线局域网可以使用，不要求局域网具备互联网连接。
- 检查为用户操作时的一次性读取，不自动打开 Wi-Fi，不增加定位/SSID 权限或后台轮询。开机及配对后自动启动入口保持原有行为，此次预检针对手动启动按钮。

## 验证记录

- Windows Release 和 Android Release 构建通过，Core 48 项、Android 11 项单元测试通过。正式包对应的 Windows Core DLL 重新执行实际 SFTP 集成验证，覆盖复制、暂停/恢复、取消清理、重试、有效前缀续传和错误 Host Key 拒绝。
- Android 发布签名与旧版一致，编译后的扫码 Activity 方向为 `fullUser`。
- 0.2.6 同功能候选包（versionCode 7）在 Note11 同签名覆盖安装，应用 UID 保持不变；实际扫码 Activity 保持竖屏，当前可用局域网下通过界面启动共享服务成功。正式版仅调整版本标识为 0.2.6 / versionCode 8 后重新构建，不把候选包真机记录描述为正式包逐项真机验收。
- Wi-Fi 关闭和未连接的启动规则已通过单元测试；为保留当时正在使用的 USB 共享连接，未切网验证相应系统设置返回流程。

保留 0.2.5 的有界上传流水线、源文件保护、两次完整远端 SHA-256 读回与安全提交。此前同一 1 GiB 随机文件三轮测试如下，本轮未重复该性能长测：

## 已知限制

- Windows 配对窗口的实际布局与点击、多网卡切换后的重新扫码仍需更多实机验证；此前窗口工具初始化失败，构建和测试不替代这部分验证。
- 本轮尚未在日用目录重新执行 Windows 覆盖安装与卸载验收。
- 资源管理器 SSHFS 盘符复制与应用内传输为独立路径，尚未完成同等三轮大文件验收；已有部分文件的续传路径性能也未优化。
- 其他设备、网络、后台/熄屏状态和大量小文件不能保证与上述大文件结果相同。Android 厂商后台策略、实际耗电改善和历史自启动提示仍需日常观察。
