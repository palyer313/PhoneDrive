# 安装 PhoneDrive 0.2.4

Windows：运行 Release 中的 PhoneDrive-0.2.4-Setup-x64.exe。面向当前用户安装到本地应用目录，提供开始菜单入口、可选桌面快捷方式和卸载程序，已包含 .NET 运行时。

挂载盘符需要单独安装官方 WinFsp 和 SSHFS-Win；链接见项目 README。未安装驱动时仍可使用文件浏览与传输。

Android：下载 PhoneDrive-0.2.4-release.apk 后覆盖安装。允许存储和通知权限，打开共享服务。需要开机和熄屏共享时，在应用设置中开启相应选项，并按厂商要求允许自启动、解除电池限制。

配对：电脑打开设备管理中的扫码连接入口，由手机扫码并在电脑确认。

更新 Windows 前从系统托盘退出旧版；升级和卸载程序会保留应用配对数据。Android 不要为降级而卸载应用，否则系统会删除其私有数据。

签名私钥和密码不分发。Android 公共签名证书使用通用 PhoneDrive 组织信息；公钥证书随 APK 保存，用于系统验证更新。
